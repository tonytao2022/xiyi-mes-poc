# 兴澄特钢功能设计对照分析（POC 深化参考）

> 依据：兴澄特钢二炼钢质量管控(AP06250702)与成本管控(AP06250701)系统功能设计v1.0
> 提取文本：`docs/质量管控_提取.txt`、`docs/成本管控_提取.txt`

## 一、兴澄两系统概览

| 维度 | 质量管控 | 成本管控 |
|------|---------|---------|
| 工序范围 | KR/BOF/LF/RH/CC 五大工序 | 同 |
| 核心单位 | 炉次（炉号贯穿） | 炉次（炉次成本核算） |
| 模块数 | 8 大功能流程 | 5 大功能流程 |
| 设计理念 | 工艺卡包->判定->监控->评价->追溯 PDCA 闭环 | 采集->建模->分摊->对比->监控闭环 |
| 数据依赖 | MES + 采集平台(SCADA点位) | MES + Tbox 数采 |

我们 POC 对应：炼钢工艺执行(转炉/精炼/真空/板坯/方坯/合金) + 废钢料型 + SWRCH22A轧钢 + 价格。**工序映射**：兴澄 KR≈我们的预处理、BOF=转炉、LF=精炼、RH=真空、CC=连铸(板坯/方坯)。

## 四、关键业务规则借鉴（可直接用）

### 质量规则
1. **质量评分**：`Score=Σ(参数得分×权重)×工序修正系数`；分段扣分(±5℃内不扣,5~10℃扣3分) vs 线性扣分(每0.01%扣1.5分)
2. **综合得分**：`综合=Σ(工序得分×工序权重)+质量缺陷扣分`
3. **SPC判异**：八大准则，优先1/2/3/7
4. **判异双标准**：内控标准(工艺卡)+厂标(自定义)
5. **异常-缺陷关联矩阵**：定位缺陷根因

### 成本规则
1. **炉次成本**：`科目物料投料量×单价=炉次成本`；`炉次成本/炉次重量=吨钢成本`
2. **4种分摊**：
   - 炉次分摊：投料量×单价
   - 浇次分摊：浇次消耗/浇次产量×炉次产量×单价（未结束按目标吨钢成本）
   - 周期分摊：消耗/(Σ产量×系数)×(炉次产量×系数)×单价
   - 定额：吨钢定额×单价×炉次产量
3. **分摊系数**：固定系数 + 按工位加工时间
4. **价格履历**：版本化(新增V0.1,修改+0.1,原失效)
5. **成本对比**：实绩/预测/目标三成本，超差红色示警
6. **记产日期**：夜班(20-08)记次日；26日班次记下月

## 五、对 v2 详细设计的修订建议

### 质量主线补充（新增二级页/功能）
1. **新增"质量评价"页**：炉次质量评分(借鉴评分算法)+历史最优指导
2. **指标分析页增 SPC**：控制图+判异(核心4准则)
3. **单件偏差页增根因**：异常-缺陷关联矩阵(偏离项->质量结果)
4. **相关性页增回归**：回归线+置信区间+R²(借鉴脱硫回归)
5. **追溯页**：一张图+红色高亮报警工序

### 成本主线补充（新增二级页/功能）
1. **成本估算页增富裕度**：合金 actual vs std 富裕成本(已有数据)
2. **成本对标页**：钢种/班组/设备/路径多维(已有数据)
3. **新增"成本模型"页(预留)**：4种分摊+炉次核算(需补数据)
4. **新增"成本监控"页(预留)**：实绩/预测/目标对比+超差(需补数据)
5. **价格行情页增履历**：价格版本趋势

### 数据可行性分层（实现优先级依据）
- **第一层·现可做**：质量评分、SPC、趋势预警、异常-缺陷关联、回归、历史最优、追溯一张图、成本对标、富裕度、价格趋势
- **第二层·需补数据**：工艺卡包、炉次成本核算、4分摊、实绩/预测/目标对比
- **第三层·第二阶段**：质量监控闭环、成本预测、配料优化

## 六、结论

兴澄是覆盖 KR-CC 全工序的生产级系统，功能完整但依赖大量 MES/数采数据。我们 POC 数据有限（无耐材/能耗/辅材/产出侧），**不能照搬**，但可借鉴其**分析逻辑和业务规则**：

1. **质量**：评分算法、SPC判异、异常-缺陷关联、追溯一张图 -- 这些用我们现有 fact_heat_indicator 数据就能做，是高价值深化点。
2. **成本**：4种分摊、炉次核算、三成本对比 -- 需补数据，先做成本对标/富裕度(有数据)，分摊模型留第二阶段用模拟数据。

建议：把"现可做"的第一层功能纳入 v3 详细设计，作为看板深化的核心内容。
