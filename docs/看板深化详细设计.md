## 三、新增/调整页详细设计

### 🆕 Q8. 轧钢工艺质量 `/quality/rolling`
> 来源：demo S3(加热)+S4(轧制)+S7(命中率)，从效率看板的温度分析归质量（符合性视角）

- **数据**：fact_heating（各段温度）+ fact_rolling（轧制温度/命中率）
- **模块**：
  - 加热工艺：各段温度(预热/加热/均热/出炉)Min/Mean/Max柱状 + 统计卡（demo S3）
  - 轧制工艺：开轧/终轧/吐丝温度时序折线（抽样）+ 班次产量与温度双轴（demo S4）
  - 命中率：A/B/C命中率分布doughnut + 区间柱状（demo S7）
- **API**：新增 heating-temperature、rolling-temperature-series、hit-rate-distribution
- **与效率看板区分**：本页看"温度是否符合工艺标准"（质量），效率看板看"节奏/产量"（效率）

### 🆕 Q9. 质量评价 `/quality/evaluate`
> 来源：兴澄⑦质量评价

- **数据**：fact_heat_indicator（judge/actual/std）+ dim_indicator（权重）
- **模块**：
  - 炉次质量评分：`Score=Σ(参数得分×权重)×工序修正系数`，按炉次算分（借鉴兴澄评分算法）
  - 历史最优指导：按钢种查历史最高分炉次，展示其工艺实绩供参考
  - 班组质量排名：班组平均得分排名
- **评分规则**（借鉴兴澄）：分段扣分(如温度±5℃内不扣,5~10℃扣3分) / 线性扣分(成分每0.01%扣1.5分)；权重暂用均权，后续可配
- **API**：新增 heat-score、history-best、team-score-ranking

### ✨ Q11. 质量追溯 `/quality/trace`
> 来源：兴澄⑧全流程追溯一张图（原预留，升可做）

- **数据**：全表（熔炼号贯穿）
- **模块**：
  - 熔炼号选择器 + 全流程时间线（配料->转炉->精炼->真空->连铸->加热->轧制->检验）
  - 每工序卡片：实绩摘要 + 符合率 + 异常指标红色高亮
  - 异常工序跳转详情
- **API**：新增 heat-trace?heat_no=
