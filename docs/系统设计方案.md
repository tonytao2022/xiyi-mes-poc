# 钢铁 MES 工艺质量·成本·效率协同优化系统 · 设计方案

> 版本：v2.0 ｜ 日期：2026-07-23 ｜ 定位：POC 设计，可演进至生产系统
> v2.0 变更：双主线升级为"三条独立主线 + 两两交汇 + 全局综合评价"结构；新增效率主线；确立以成本为核心的货币化全局优化目标

---

## 一、设计理念

### 1.1 核心理念：三线独立·渐进交汇·货币化统一

炼钢经营的本质是 **"质量、成本、效率"** 三角平衡。本系统的设计哲学：

- **三条主线各自独立闭合**：质量、成本、效率各有完整的分析逻辑、场景与原生指标，不为交汇而存在，能独立产出价值。
- **两两交汇渐进产生**：随业务延展，质量×成本、质量×效率、成本×效率的交点会一个个浮现，每发现一个就多一个优化抓手。
- **全局综合评价以成本为核心**：顶层不是一个具体指标（如终点命中率只是其中一个场景），而是一个综合性评价指标--以成本为统一口径，把质量损失和效率损失都折算为成本，形成标量。
- **全局优化目标**：`min 综合炉次成本 = 直接成本 + 质量损失成本 + 效率损失成本`，这是系统的"总账"和"北极星"。

### 1.2 设计原则

1. **以熔炼号为追溯主键**，贯穿原料->炼钢->连铸->轧钢->检验全链路。
2. **价格是配料逻辑的一等公民**，作为数据架构与优化模型的核心输入，不事后补足。
3. **三条线统一四层结构**（L1底座-L2监控-L3诊断-L4优化），独立展开。
4. **货币化统一**：所有损失最终折算为成本口径，形成单一可比的优化目标。
5. **POC 优先可用**：基于现有数据即可跑通核心链路，缺口数据通过估算/公开数据渐进补齐。
6. **演进式架构**：从静态分析到动态优化，技术栈平滑升级。

### 1.3 系统分层总览

```
终极层  全局优化目标  min 综合炉次成本 = 直接成本 + 质量损失 + 效率损失
            ↑ 汇入
顶层    全局综合评价  综合炉次成本核算 · 损失结构分析 · 综合对标 · 优化仿真
            ↑ 收口
中层    两两交汇场景  质量×成本 · 质量×效率 · 成本×效率（渐进产生）
            ↑ 支撑
底层    三条独立主线  质量线 · 成本线 · 效率线（各自四层，独立闭合）
```

## 二、业务架构

### 2.1 质量主线（独立）

**世界观**：问"好不好、稳不稳、异常在哪"

| 层级 | 能力 | 核心场景 | 原生指标 |
|------|------|---------|---------|
| L1 数据底座 | 工艺质量数据模型 | 围绕熔炼号的加热/轧制/尺寸/力学/化学成分事实-维度模型 | - |
| L2 基线与监控 | 统计基线 + 符合率 + SPC | 各牌号基线(mean±std,p05/p95)、工艺符合率看板、控制图、Cp/Cpk | 合格率、Cp/Cpk |
| L3 偏差与根因 | 单件偏差 + 异常下钻 | z-score五级评级、异常项展开到工序/参数级根因 | 偏差度 |
| L4 优化与预测 | 窄控制 + 质量预测 | 成分窄控制建议、工艺参数->质量结果预测 | - |

### 2.2 成本主线（独立）

**世界观**：问"花了多少、该花多少、哪可省"

| 层级 | 能力 | 核心场景 | 原生指标 |
|------|------|---------|---------|
| L1 数据底座 | 投入产出数据 | 配料/合金/能耗/耐材投入，产出重量闭环 | - |
| L2 实物量与估算 | 结构 + 价格换算 | 配料结构、合金富裕度、价格×实物量=估算金额 | 吨钢成本、钢铁料消耗、合金单耗 |
| L3 成本诊断 | 对标 + 归因 | 钢种/路径/班组成本对标、损失归因（命中率/收得率/富裕） | 单位成本差异 |
| L4 成本优化 | 配料优化 + 窄控制 | 价格驱动配料线性规划、合金加入量优化、低效炉次预警 | - |

### 2.3 效率主线（独立）

**世界观**：问"快不快、顺不顺、卡在哪"

| 层级 | 能力 | 核心场景 | 原生指标 |
|------|------|---------|---------|
| L1 数据底座 | 工序时长/时刻数据 | 由时间戳推算各工序时长、等待时间、炉次间隔 | - |
| L2 节奏监控 | 周期分布 + 节拍匹配 + 产能 | 冶炼周期分布、炼钢-连铸节拍匹配、班次/设备小时产量、作业率 | 冶炼周期、作业率、小时产量 |
| L3 效率诊断 | 超时归因 + 瓶颈识别 | 超时炉次归因（等钢水/等设备/补吹）、瓶颈工序定位、等待时间分析 | 等待时长、瓶颈度 |
| L4 效率优化 | 工艺时长优化 + 调度 | 质量不降前提下的最短工艺时长、连浇炉数优化、节奏调度建议 | - |

**效率线数据基础**：现成可用。转炉（吹氩/出钢/补吹时长）、精炼（精炼/软吹/通电时长）、真空（循环时长）、加热（入出炉时刻/加热时间）、轧制（轧制时间/根数/班次）均为时长/时刻字段，重新按效率维度组织即可，无需新数据。

### 2.4 两两交汇场景（渐进产生）

交点随业务深入逐个浮现，每条交点是一个具体可落地的分析场景：

**质量 × 成本**
- 质量损失成本（废品/返工返炼/降级损失）
- 配料成本-合格率权衡（低端料配比 vs 合格率，找最优平衡点）
- 合金富裕成本（成分偏上的过量合金）
- 质量预防投入 vs 损失避免（COQ平衡）

**质量 × 效率**
- 工艺时长-质量关系（精炼时长 vs 夹杂物，找质量不降的最短时长）
- 一次成功率（一次拉成省时且质量好）
- 返工的效率损失（返炼既伤质量又费时间）

**成本 × 效率**
- 时长-能耗成本（时间 × 单位时间能耗/耐材）
- 等待温降补热成本
- 连浇炉数-开停损耗成本
- 产能利用率-固定成本分摊

### 2.5 全局综合评价（顶层）

以成本为核心口径，将质量损失和效率损失货币化，形成 **综合炉次成本**：

```
综合炉次成本 = 直接成本 + 质量损失成本 + 效率损失成本
```

**1. 直接成本**（成本线原生）
- 钢铁料、合金、能源、耐材

**2. 质量损失成本**（质量折算为成本，COQ模型）
- 废品损失 = 废品量 × (吨钢成本 - 残值)
- 返工返炼成本 = 返工能耗 + 返工合金 + 返工时间成本
- 降级损失 = 降级量 × (正常价 - 降级价)
- 富裕损失 = 成分偏上导致的过量合金/原料成本
- 外部损失 = 客诉赔偿 + 退货损失（数据成熟后纳入）
- 预防/鉴定成本 = 检验、控制投入

**3. 效率损失成本**（效率折算为成本）
- 等待温降补热 = 等待时长 × 温降速率 × 补热能耗单价
- 产能闲置机会成本 = 闲置时长 × 小时边际利润
- 补吹损失 = 补吹氧气 + 烧损钢铁料 + 合金补偿
- 连浇中断损失 = 开停浇损耗 + 耐材 + 准备时间成本
- 故停损失 = 停机时长 × 小时边际利润

### 2.6 全局优化目标（终极层）

```
min  综合炉次成本 = 直接成本 + Σ质量损失 + Σ效率损失
```

能力产出：
1. **全厂综合成本对标**：每炉/每钢种/每班组一个综合成本数，直接排名
2. **损失结构分析**：钱漏在质量/效率/直接成本哪一块，定优化优先级
3. **最优实践识别**：综合成本最低的炉次反推工艺与配料特征
4. **优化目标函数升级**：配料优化从"直接成本最低"升级为"综合成本最低"（可能用稍贵料但减少质量损失，综合更省）
5. **决策仿真**：调一个参数，看三块成本此消彼长，找全局最优点

## 三、数据架构

### 3.1 核心数据模型

围绕熔炼号的星型模型：

**事实表**：
- `fact_heat_process`（炉次工艺事实）：转炉/精炼/真空/连铸各工序工艺实绩与判定、工序时长与时刻
- `fact_heat_cost`（炉次成本事实）：配料/合金/能耗/耐材投入，产出重量
- `fact_material_inspect`（物料检验事实）：力学/化学/尺寸检验记录
- `fact_rolling`（轧制事实）：加热/轧制实绩
- `fact_loss`（损失事实）：质量损失、效率损失明细（折算金额与物理量）

**维度表**：
- `dim_heat`（熔炼号维）：熔炼号、炉批号、试批号、材料号追溯关系
- `dim_steel_grade`（钢种维）：牌号、标准、规范码、工艺路径
- `dim_team_equipment`（班组设备维）：班组(A/B/C/D)、设备号
- `dim_scrap_type`（废钢料型维）：11种料型、收得率、杂质含量
- `dim_alloy`（合金维）：23种合金、收得率、主元素含量
- `dim_energy`（能源维）：能源类型、单价、单位时间消耗
- `dim_price`（价格维）：料型/合金/能源价格时序
- `dim_process_standard`（工艺标准维）：各参数标准范围、标准时长
- `dim_loss_type`（损失类型维）：质量/效率损失分类、折算系数

**追溯键链**：熔炼号 -> 炉批号 -> 试批号 -> 材料号 -> 成品批次

### 3.2 现有数据源映射

| 现有数据 | 映射到 | 三线支撑 |
|---------|--------|---------|
| SWRCH22A(1).xls 5个sheet | fact_material_inspect, fact_rolling, dim_heat | 质量线(检验/轧制) + 效率线(加热/轧制时长) |
| 废钢料型250713.xlsx | fact_heat_cost(配料侧), dim_scrap_type | 成本线(投入) |
| 炼钢工艺执行.xlsx 7个sheet | fact_heat_process, 合金加入量->fact_heat_cost | 质量线(符合率) + 成本线(合金/能耗) + 效率线(时长/时刻) |
| 棒线材整体分析报告PDF | 质量线L2基线（参考样板） | - |
| 棒线材单块物料分析报告PDF | 质量线L3偏差（参考样板） | - |

### 3.3 价格数据接入方案

价格对配料逻辑影响是决定性的，作为数据架构与优化模型的一等公民。

**数据源**：

| 数据类别 | 推荐数据源 | 粒度 |
|---------|-----------|------|
| 废钢料型报价 | 我的钢铁网(mysteel)废钢频道、富宝资讯(f139)废钢分会 | 分地区×料型×日报 |
| 铁合金报价 | 上海有色网(SMM)铁合金、铁合金在线 | 分品种×日报 |
| 生铁/钢坯报价 | 我的钢铁网 | 日报 |
| 工业能源价格 | 各地发改委/电网工业气电价 | 月度/季度 |

**采集方式（分级演进）**：
- P0（立即）：人工维护价格表，按周更新
- P1（中期）：定时任务抓取公开报价/对接数据服务API，日级同步
- P2（长期）：对接企业内部采购/ERP系统实时采购价

**价格表结构**：
```
dim_price
- price_id, category(scrap/alloy/energy), item_code, item_name
- region, price_date, unit_price, currency, change_pct
- source, data_quality(verified/estimated)
- effective_from, effective_to
```

**价格运用**：成本换算（实物量×单价）、配料优化目标函数系数、价格敏感度仿真、历史成本趋势、采购决策支持。

### 3.4 数据缺口与补齐

| 缺口数据 | 影响 | 补齐方式 |
|---------|------|---------|
| 产出侧重量（合格坯/切废/废品） | 收得率、成本分摊到有效产出 | 优先补连铸产出计量 |
| 能源实耗（氧/氩/电/煤气） | 能耗成本精确核算 | 短期工艺参数估算，长期对接能源计量 |
| 耐材消耗与炉龄 | 耐材成本分摊 | 按炉次定额分摊估算 |
| 合金收得率实测 | 合金成本优化精度 | 短期行业经验值，长期成分反算 |
| 质量损失明细（废品/返工/降级量） | 质量损失成本核算 | 补质量异常台账 |
| 边际利润/产品价格 | 效率机会成本、降级损失 | 接入销售价格体系 |

## 四、功能架构

### 4.1 功能模块

```
钢铁MES质量·成本·效率协同优化系统
│
├─ 质量主线（独立）
│   ├─ 全流程质量追溯（熔炼号时间线）
│   ├─ 工艺符合率监控（转炉/精炼/真空/连铸下钻）
│   ├─ SPC过程能力分析（控制图、Cp/Cpk）
│   ├─ 单件物料偏差分析（z-score五级评级）
│   └─ 异常根因下钻（偏差->工序/参数级）
│
├─ 成本主线（独立）
│   ├─ 配料成本分析（料型结构、成本占比、班组对标）
│   ├─ 合金成本分析（富裕度、收得率、窄控制空间）
│   ├─ 成本估算与对标（钢种/路径/班组成本）
│   └─ 配料优化（价格驱动线性规划）
│
├─ 效率主线（独立）
│   ├─ 冶炼周期与节奏监控（周期分布、节拍匹配）
│   ├─ 产能与作业率分析（小时产量、设备作业率、连浇炉数）
│   ├─ 超时与等待诊断（超时归因、等待时间分析）
│   └─ 瓶颈识别与调度优化
│
├─ 两两交汇分析
│   ├─ 质量×成本：质量损失成本、配料-合格率权衡、合金富裕成本
│   ├─ 质量×效率：工艺时长-质量关系、一次成功率
│   └─ 成本×效率：时长-能耗成本、等待损失、连浇-开停损耗
│
├─ 全局综合评价（顶层）
│   ├─ 综合炉次成本核算（直接+质量损失+效率损失）
│   ├─ 损失结构分析（钱漏在哪）
│   ├─ 综合成本对标与最优实践识别
│   └─ 决策仿真（参数调整->三块成本此消彼长）
│
└─ 公共支撑
    ├─ 价格管理（价格表、行情趋势、敏感度）
    ├─ 数据管理（数据源、数据质量、ETL）
    └─ 报表导出（PDF/Excel，沿用现有报告范式）
```

### 4.2 优先落地场景

**场景A · 全流程质量追溯链**（质量线）：熔炼号下钻"配料->炼钢->连铸->轧钢->检验"全画像。数据全具备。

**场景B · 配料成本-质量权衡**（质量×成本交点）：废钢料型+成分命中率+价格，回答"低端料配比提到X%、成本降多少、合格率降多少、最优平衡点"。即时价值最高。

**场景C · 合金富裕度与收得率**（成本线）：标准vs实绩，量化合金优化空间。

**场景D · 单件异常根因下钻**（质量线L3）：z-score严重/偏离项自动展开到工序/参数级。

**场景E · 配料优化模型**（成本线L4）：价格驱动混合整数规划，支持敏感度仿真。

**场景F · 冶炼周期与瓶颈诊断**（效率线）：周期分布、超时归因、节拍匹配，时长数据现成。

**场景G · 综合炉次成本核算与对标**（顶层）：每炉综合成本=直接+质量损失+效率损失，全厂对标，损失结构分析。这是系统的"总账"。

**场景H · 全局优化仿真**（终极）：调工艺/配料参数，看综合成本变化，找全局最优点。从"分析"到"优化"的闭环。

## 五、技术架构

### 5.1 推荐技术栈

| 层 | 推荐选型 | 理由 |
|----|---------|------|
| 前端 | Vue3 + Element Plus + ECharts | 工业看板支持强，组件化便于三主线模块化 |
| 备选前端 | 原生HTML + Chart.js | 与现有demo一致，POC快速验证 |

| 部署 | Docker Compose | 一键起前后端+数据库 |

## 七、关键设计决策点（待确认）

1. **技术栈**：推荐 Vue3+FastAPI+PostgreSQL；求最快验证可先用 HTML+Chart.js+Python 脚本。需确认倾向。
2. **首个亮点场景**：建议从场景B（配料成本-质量权衡）切入，即时价值高且数据完备；是否认可。
3. **价格数据源**：是否有付费数据服务，还是先用公开页面人工录入起步？
4. **产出侧重量数据**：能否获取连铸产出重量，补齐收得率闭环？决定成本核算精度上限。
5. **质量/效率损失折算系数**：降级价差、小时边际利润、温降补热能耗等折算参数，是否有现成口径，还是需先约定估算值？
6. **前端形态**：先做可交互看板，还是先做可导出报告（沿用PDF范式）？
