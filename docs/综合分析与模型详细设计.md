# 综合性场景与模型详细设计（创举性核心）

> 版本：v1.0 ｜ 日期：2026-07-29 ｜ 定位：双维度交汇 + 三维度综合炉次成本模型 + 模拟能力，系统创举性设计
> 依据：设计方案 v2/v3 货币化统一思想 + 兴澄 COQ/分摊逻辑 + 现有数据底座

---

## 一、设计目标与定位

这是区别于普通 MES 看板的**创举性设计**：

1. **双维度交汇**：质量×成本、质量×效率、成本×效率 的两两交叉分析，揭示单线分析看不到的权衡与冲突。
2. **三维度综合炉次成本模型**：把质量损失和效率损失都**折算为成本**，形成标量 `综合炉次成本 = 直接成本 + 质量损失成本 + 效率损失成本`，统一三主线为经济口径。
3. **模型模拟能力**：基于综合成本模型，做配料优化、参数仿真、情景对比、敏感度分析，**体现模型价值**（不只是看数，而是算最优）。

**核心思想**：质量=做得好（结果），成本=花得省（经济），效率=做得快（时间）。三者最终统一到"元"，形成 `min 综合炉次成本` 的全局优化目标。

## 二、双维度交汇分析

### 2.1 质量 × 成本交汇

| 交汇场景 | 业务含义 | 口径/算法 | 数据来源 | 状态 |
|---------|---------|----------|----------|------|
| **合金富裕损失** | 成分偏上导致的过量合金浪费 | Σ (actual − std上限) × 合金单价，仅 actual>std 上限的合金 | fact_heat_indicator(合金 actual/std) + dim_price | ✅有数据 |
| **补吹损失** | 终点未命中导致补吹的氧气/烧损/合金补偿 | 补吹次数 × (氧气单价×用量 + 钢铁料烧损 + 合金补偿估算) | fact_heat_indicator(补吹出钢 judge=0) | ✅有数据(估算) |
| **配料-合格率权衡** | 低端料配比 vs 成分命中率的最优平衡 | 按废钢配比分组算成分命中率，找成本下降 vs 合格率下降的平衡点 | fact_scrap_ratio + fact_heat_indicator(成分) | ✅有数据 |
| **质量损失成本(COQ基础)** | 低分炉次的预估损失 | (1−符合率) × 炉次预估产量 × 吨钢成本 × 损失系数 | fact_heat_indicator(符合率) | ✅估算 |
| **废品/返工/降级损失** | 不合格品的实物损失 | 废品量×(吨钢成本−残值) + 返工成本 + 降级差价 | 需模拟（产出侧） | 🔵需模拟 |

### 2.2 质量 × 效率交汇

| 交汇场景 | 业务含义 | 口径/算法 | 数据来源 | 状态 |
|---------|---------|----------|----------|------|
| **工艺时长-质量关系** | 精炼/镇静时长 vs 符合率，找"质量不降的最短时长" | 按时长分箱算各箱符合率，拟合曲线找拐点 | fact_heat_indicator(时长+judge) | ✅有数据 |
| **一次成功率** | 一次拉成省时且质量好 | 1 − (补吹/二次出钢炉次占比)，关联质量损失 | fact_heat_indicator(补吹/二次出钢) | ✅有数据 |
| **时长异常-质量** | 超长炉次的质量表现 | 时长>P95 的炉次 vs 正常炉次的符合率对比 | fact_heat_indicator | ✅有数据 |
| **返工效率损失** | 返炼既伤质量又费时 | 返工炉次 × (返工时长成本 + 质量降级) | 需模拟 | 🔵需模拟 |

### 2.3 成本 × 效率交汇

| 交汇场景 | 业务含义 | 口径/算法 | 数据来源 | 状态 |
|---------|---------|----------|----------|------|
| **时长-能耗成本** | 时间就是能耗成本 | 各工序时长 × 单位时间能耗单价 | fact_heat_indicator(时长) + 能耗单价估算 | ✅估算 |
| **超时损失** | 超时炉次的额外成本 | (实际时长 − 标准时长) × 单位时间成本 | fact_heat_indicator(时长) | ✅估算 |
| **等待温降补热** | 等待导致温降需补热 | 等待时长 × 温降速率 × 补热能耗单价 | 需推算等待时长 | 🟡部分 |
| **连浇-开停损耗** | 连浇少则开停浇损耗 | (标准连浇 − 实际) × 单次开停成本 | 需连铸连浇数据 | 🔵需模拟 |
| **产能闲置机会成本** | 闲置的边际利润损失 | 闲置时长 × 小时边际利润 | 需模拟边际利润 | 🔵需模拟 |

> 双维度交汇中 ✅ 的部分用现有数据即可实现，🔵 需模拟数据。建议先做 ✅ 的，🔵 纳入综合模型时用模拟数据补齐。

## 三、三维度综合炉次成本模型

### 3.1 模型定义

```
综合炉次成本 = 直接成本 + 质量损失成本 + 效率损失成本
```

每个炉次都可计算此标量，支持全厂对标、损失结构分析、优化优先级。

### 3.2 直接成本（成本线原生，✅有数据）

| 项 | 公式 | 数据 |
|---|------|------|
| 钢铁料 | 废钢配比×重量×单价（钢种级估算） | fact_scrap_ratio + dim_price |
| 合金 | 合金加入量×单价（炉次级） | fact_heat_indicator(合金) + dim_price |
| 能源 | 时长×单位能耗单价（估算） | fact_heat_indicator(时长) + 能耗单价 |
| 耐材 | 按炉次定额分摊（估算） | 定额估算 |

### 3.3 质量损失成本（质量折算为成本，COQ模型）

| 项 | 折算公式 | 数据 | 状态 |
|---|---------|------|------|
| **富裕损失** | Σ (actual − std上限) × 合金单价（actual>上限） | fact_heat_indicator + dim_price | ✅ |
| **补吹损失** | 补吹炉次 × (氧气 + 烧损 + 合金补偿) | fact_heat_indicator | ✅估算 |
| **废品损失** | 废品量 × (吨钢成本 − 残值) | 模拟废品量 | 🔵模拟 |
| **返工返炼** | 返工能耗 + 返工合金 + 返工时间成本 | 模拟返工 | 🔵模拟 |
| **降级损失** | 降级量 × (正常价 − 降级价) | 模拟降级 | 🔵模拟 |
| **预防/鉴定** | 检验、控制投入（按炉次分摊） | 估算 | 🟡估算 |

> 废品/返工/降级量可**按符合率估算**：符合率越低，废品/降级率越高（设定映射关系，如符合率<80%时废品率2%、降级率5%）。

### 3.4 效率损失成本（效率折算为成本）

| 项 | 折算公式 | 数据 | 状态 |
|---|---------|------|------|
| **超时损失** | Σ (实际时长 − 标准时长) × 单位时间成本 | fact_heat_indicator(时长) | ✅ |
| **时长-能耗** | 时长 × 单位时间能耗单价 | fact_heat_indicator | ✅估算 |
| **补吹损失(效率)** | 补吹炉次 × 补吹时长 × 单位时间成本 | fact_heat_indicator | ✅ |
| **等待温降补热** | 等待时长 × 温降速率 × 补热能耗单价 | 推算等待 | 🟡部分 |
| **产能闲置** | 闲置时长 × 小时边际利润 | 模拟边际利润 | 🔵模拟 |
| **连浇中断** | (标准连浇 − 实际) × 单次开停成本 | 模拟连浇 | 🔵模拟 |
| **故停损失** | 停机时长 × 小时边际利润 + 恢复成本 | 模拟故停 | 🔵模拟 |

### 3.5 全局优化目标

```
min  综合炉次成本 = 直接成本 + Σ质量损失 + Σ效率损失
```

产出能力：
1. **全厂综合成本对标**：每炉/钢种/班组/设备一个综合成本标量，排名
2. **损失结构分析**：钱漏在直接/质量损失/效率损失哪块，定优化优先级
3. **最优实践识别**：综合成本最低炉次反推工艺与配料特征
4. **优化目标升级**：配料优化从"直接成本最低"升级为"综合成本最低"

## 四、模型模拟能力（高级功能）

### 4.1 配料优化（线性规划）

**目标**：求最低综合成本配料方案

```
min  Σ c_i · x_i  (c_i: 料型i综合成本，含质量损失预估)
s.t. Σ r_i · x_i ≥ M          (金属量需求, r_i: 收得率)
     Σ e_ij · r_i · x_i ≤ U_j  (杂质元素j不超标)
     x_i ≤ Q_i                 (各料型可用量)
     Σ x_i = W                  (总投料量)
     质量约束(成分命中率)        (配比->命中率预估)
```

参数化输入：价格/收得率/质量要求/可用量。输出最优配料 + 综合成本 + 与现状对比。

### 4.2 参数仿真

**目标**：调工艺参数，看三块成本此消彼长，找全局最优

- 输入：某工艺参数调整（如精炼时长−10%、补吹率降5%、配比调整）
- 计算：直接成本、质量损失、效率损失的变化
- 输出：综合成本变化（可能直接成本降但质量损失升），找全局最优点
- 可视化：三块成本此消彼长曲线 + 综合成本曲线

### 4.3 情景对比

**目标**：多方案综合成本对比

- 定义多个方案（如方案A现状、方案B优化配料、方案C缩短精炼）
- 算每方案的综合成本 + 损失结构
- 对比表/雷达图，选最优

### 4.4 敏感度分析

**目标**：价格/收得率/质量波动对综合成本的影响

- 输入：某变量波动范围（如废钢价格±10%、收得率±2%、废品率±1%）
- 输出：综合成本变化曲线 + 弹性系数
- 识别：哪些变量对综合成本影响最大（优化杠杆点）

## 五、数据需求与模拟数据生成

### 5.1 现有数据可支撑的损失折算（✅ 立即可做）

- 合金富裕损失（actual vs std × 价格）
- 补吹损失（补吹指标 × 估算）
- 超时损失（时长 × 估算）
- 时长-能耗（时长 × 单耗估算）
- 配料-合格率权衡

### 5.2 需模拟数据补齐（🔵 综合模型必需）

| 模拟数据 | 生成方式 | 用途 |
|---------|---------|------|
| **产出侧重量** | 投入 × 收得率(钢种0.90-0.95) | 收得率、吨钢成本分母 |
| **废品/降级量** | 产量 × 废品率(按符合率映射) | 质量损失成本 |
| **返工量** | 低分炉次 × 返工率 | 质量损失 |
| **能耗实耗** | 时长 × 单位能耗(工序) | 能源成本 |
| **边际利润** | 钢种售价 − 直接成本 | 效率机会成本 |
| **耐材** | 按炉次定额 | 耐材成本 |

**模拟数据生成原则**：
- 基于现有真实数据派生（投入/时长/符合率 -> 产出/损失）
- 标注 `source=模拟`，与真实数据区分
- 参数可调（收得率/废品率映射/单价），便于客户接入真实值后替换
- 与客户沟通后用真实数据替换模拟值

### 5.3 折算系数口径（估算值，待客户确认）

| 系数 | 估算值 | 说明 |
|------|--------|------|
| 收得率 | 0.90-0.95(按钢种) | 投入->产出 |
| 废品率映射 | 符合率<80%→2%, 80-90%→1%, >90%→0.3% | 符合率->废品 |
| 降级率映射 | 符合率<80%→5%, 80-90%→2% | 符合率->降级 |
| 残值率 | 0.7 | 废品残值占吨钢成本 |
| 能耗单价 | 氧气2元/m³、电0.7元/kWh | 能源 |
| 单位时间成本 | 按工序定额 | 超时/等待 |
| 小时边际利润 | 钢种售价−直接成本 | 产能机会成本 |

## 六、实现路径与优先级

### 第一批·双维度交汇（✅现有数据，立即）
- 质量×成本：合金富裕损失 + 补吹损失 + 配料-合格率权衡
- 质量×效率：工艺时长-质量关系 + 一次成功率
- 成本×效率：时长-能耗 + 超时损失
- **产出**：交汇分析页（质量/成本/效率看板各加交汇section，或独立"综合分析"页）

### 第二批·综合炉次成本模型（需模拟数据）
- 模拟数据生成（产出侧/损失明细/能耗/边际利润）
- 综合成本核算（直接+质量损失+效率损失）
- 损失结构分析 + 综合对标 + 最优实践
- **产出**：综合炉次成本看板（损失结构饼图+对标排名+最优炉次）

### 第三批·模型模拟能力（体现模型价值）
- 配料优化（线性规划求解器）
- 参数仿真（调参算综合成本）
- 情景对比（多方案）
- 敏感度分析（变量弹性）
- **产出**：模型模拟工作台（配料优化器+仿真器+情景对比+敏感度）

### 里程碑
- M1：双维度交汇上线（现有数据，揭示权衡）
- M2：综合炉次成本模型上线（货币化统一，总账建立）★ 创举核心
- M3：模型模拟工作台上线（算最优，体现模型价值）★ 创举延伸
